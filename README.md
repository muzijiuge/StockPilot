# A股韭菜盒子 v1.3.20

这是一个仅保留 A 股能力的 VS Code 本地扩展。界面参考 LeekHub/leek-fund README 的公开截图独立实现，提供行情侧栏、自选、资产、资讯、板块行情和大盘云图，不包含数据中心、基金、港美股、期货、外汇或数字货币。

## v1.3.19 同花顺社区瀑布流

- 个股右键菜单增加“查看同花顺社区”，在当前侧栏内切换到只读社区页，左上角可返回原行情列表。
- 社区首次加载 20 条，滚动接近底部后自动续取下一页并去重；卡片按侧栏宽度使用单列或双列瀑布流，支持头像、正文、图片、标签和互动数据展示。
- 社区展示热门动态，支持刷新和滚动加载。
- 社区页只允许打开同花顺 HTTPS 帖子链接，不提供评论或点赞写操作。进入社区后暂停侧栏行情与板块后台轮询，返回行情页后恢复。

## v1.3.18 轻量板块排行与完整成分股

- 侧栏行业/概念排行改接同花顺可指定返回数量的轻量接口，每种排行每轮由服务端直接返回 20 条，不再为侧栏下载完整板块目录。
- “行业板块”和“概念板块”标题尾部增加排序切换按钮；默认按当日涨幅排序，点击后切换到同花顺官方板块热榜，再次点击恢复涨幅排序。
- 中心页行业/概念列表仍独立加载同花顺全量板块行情，不受侧栏 TOP20 限制。
- 板块详情改用完整成分股行情，并在展示前按当日涨跌幅从高到低排序；概念目录路由码会自动映射到对应的同花顺行情板块码。

## v1.3.17 同花顺板块与直达加载

- 侧栏行业/概念涨幅榜和板块列表改用同花顺公开板块目录及原生代码，不再混入东方财富的“昨日首板”等事件标签。
- 点击侧栏板块时会把板块摘要一并传入中心页，并在请求开始时立即切换到详情视图；成分股直接读取对应的同花顺行业或概念详情，首次打开无需再手动刷新。
- 同花顺 GBK 页面按响应编码解码，并在临时限流时保留最近一次有效榜单，避免自动刷新把已有内容清空。

## v1.3.16 多分组与启动防闪屏

- 分组成员关系升级为多选：再次通过“添加 A 股”选择已有股票并指定新分组时，同一股票可以同时保留在多个分组；已有单分组数据会自动兼容迁移。

## 功能

- VS Code Webview 侧栏：我的持仓、A 股、指数、行业板块 TOP20 和概念板块 TOP20，支持红涨绿跌、实时刷新和三态排序；排序按钮依次切换默认顺序、涨跌幅升序和涨跌幅降序，各行情分组均按当日涨跌幅排序。
- LeekFund 风格的添加股票联想：在同一个输入框中按代码、名称或拼音实时显示匹配的 A 股及 A 股指数。
- 原创单色 SVG 图标系统：统一品牌、自选、资产、资讯、大盘云图、板块行情和操作按钮的尺寸与线宽，并将顶部栏压缩为 56px。
- LeekFund 同路线实时走势页：点击侧栏股票后打开或复用东方财富完整行情页，可切换分时、5 日、5/15/30/60 分钟、日 K、周 K、月 K，并查看资金流与逐笔成交。
- 实时页由仅监听 `127.0.0.1` 的随机端口和随机令牌代理承载，使用初始 GET 快照与 SSE 流式推送；iframe 与页面实例常驻，数据变化不会触发 Webview 整页重建。
- K 线沿用 LeekFund 的稳定性策略：日/周/月线优先使用搜狐历史日线转换，5/15/30/60 分钟线使用东方财富分时数据聚合；备源异常时才回到原始 K 线分片。
- 自选中心公司资料：展示企业简介、主营业务、所属行业、细分行业、相关概念、同花顺 1 小时热度、雪球关注人数和同花顺近一个自然月异动解读。
- 侧栏板块排行：行业板块、概念板块各使用只返回 20 条的轻量请求，可在当日涨幅和同花顺热度排序间切换；持仓行显示当日涨跌幅，“我的持仓”标题显示相对成本价的实时总盈亏百分比。
- 紧凑板块行情：提供关注板块、3 日涨幅、3 分钟涨速、行业/概念主力净流入 TOP10、全量行业与概念列表、排序搜索和按涨跌幅排列的完整板块成分股；支持关注板块、成分股查看走势及加入自选。
- 本地资产账本：数量、成本、股票市值、当日盈亏、持仓盈亏。
- 东方财富 7×24 市场资讯。
- 三级大盘云图：按“一级行业 → 细分行业 → 个股”呈现，支持 A 股全图、上证、深证、北交所、科创板和创业板范围；面积按总市值、颜色按涨跌幅。
- 状态栏展示上证指数和本地持仓盈亏。

## 行情刷新与交易时段

- `aShareLeek.refreshInterval` 默认是 `3000` 毫秒，允许范围是 `3000–300000` 毫秒；调度采用“本轮完成后再等待一个间隔”，因此实际周期为请求耗时加配置间隔。它只调度侧栏和韭菜中心，实时走势由 SSE 到达即更新。
- `aShareLeek.requestOutsideTradingHours` 默认是 `false`。关闭时，仅在北京时间工作日 `09:15–11:30`、`13:00–15:05` 放行自动行情请求；其余盘前、午间、盘后、周末和内置的 **2026 年**交易所节假日暂停股票/指数、云图、板块轮询与实时走势上游 SSE。手动打开或切换股票仍允许一次初始页面和快照请求；手动打开云图或切换云图范围会请求一次最近收盘快照。
- 侧栏、状态栏和资产共用同一份默认 3 秒报价快照；只有侧栏或韭菜中心可见时才轮询这份快照，两者均不可见时停止后台报价请求。资产只在本地计算市值与盈亏，不发独立行情请求。休市不轮询时优先恢复本机最近有效报价；从未取得过报价的标的显示 `--`。
- 资讯仅在韭菜中心可见且“资讯”页激活时约每 `120` 秒更新，不受休市门控；公司资料按股票缓存 `30` 分钟，没有独立定时器。
- 云图仅在中心可见且“云图”页激活时约每 `300` 秒自动更新；休市时后台自动更新暂停。用户点开云图或切换范围时，先显示最近成功缓存，同时强制获取一次数据源当前可提供的最近收盘快照。中心板块列表约每 `60` 秒、板块详情约每 `15` 秒更新；侧栏板块在展开时立即请求一次，随后每 `10` 秒更新。自动请求均遵循休市设置，侧栏收起后其板块定时器会停止。
- 手动刷新和手动切换 K 线周期不受交易时段限制；实时走势无需按 3 秒手动刷新，交易时段内由 SSE 持续增量更新。
- 交易时段按北京时间判断；接口数据可能存在交易所或数据源延迟。

可在 VS Code 设置中搜索 `A股韭菜盒子` 修改这些选项。

## 构建与测试

需要 Node.js 20+ 与 VS Code 1.100+。

    npm install
    npm run check
    npm run package

确定性交易时段测试也可以单独运行：

    npm run compile
    node test/market-hours.js
    npm run test:proxy

生成的 VSIX 位于：

    dist/a-share-leek-1.3.21.vsix

安装：

    code --install-extension dist/a-share-leek-1.3.21.vsix --force

## 数据与隐私

- 行情、K 线、公司资料、资金流、最近成交、股票列表与资讯来自公开网络接口，接口可能调整、延迟或中断。
- 实时走势代理只监听本机回环地址并使用不可预测的临时令牌；浏览器代理入口只允许东方财富域名，服务端 K 线备源另固定访问 `q.stock.sohu.com`。关闭扩展时会同时关闭代理和 SSE 连接。
- 持仓、最近有效报价和最近成功的云图快照只保存在 VS Code 的本地 `globalState`，本扩展不连接券商账户，也不上传这些数据。
- 本扩展仅用于数据展示，不构成投资建议。投资有风险，入市需谨慎。
