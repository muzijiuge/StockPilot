# A股韭菜盒子 v1.3.5

这是一个仅保留 A 股能力的 VS Code 本地扩展。界面参考 LeekHub/leek-fund README 的公开截图独立实现，保留原生行情侧栏，并提供自选、资产、资讯、板块行情和大盘云图，不包含数据中心、基金、港美股、期货、外汇或数字货币。

## v1.3.5 LeekFund 同源股票搜索

- 股票联想改用 LeekFund 4.2.9 官方源码同款的腾讯证券 SmartBox：输入“视”可返回完整的相关 A 股长列表，输入 `sh` / `sz` / `bj` 可按市场前缀浏览并滚动选择。
- 保留代码、中文名称和拼音缩写实时查询；中文与市场前缀继续使用 VS Code 原生 Quick Pick 过滤排序，拼音候选则显式保持可见。
- 结果严格限制为沪、深、北 A 股及 A 股指数，过滤腾讯结果中的港股、美股、基金、ETF 和 LOF；腾讯接口异常时会明确提示重试，不会再用不完整的候选集冒充完整搜索结果。

## v1.3.4 实时股票联想

- “添加 A 股”改为 LeekFund 风格的单窗口实时 Quick Pick：输入代码、中文名称或拼音缩写后，100ms 防抖更新候选，结果按 `sh600036 | 招商银行` 格式展示并支持键盘选择确认。
- 增加请求版本保护，快速连续输入时较晚返回的旧查询不会覆盖当前候选；拼音查询结果不会被 VS Code 本地中文模糊过滤隐藏。
- 补充 Git 忽略规则，排除依赖、编译/打包输出、VSIX、浏览器测试配置、生成的预览页和视觉回归截图。

## v1.3.3 修复与性能优化

- 修复盘前、休市或行情源临时返回零值时，侧边栏、状态栏和资产页显示 `0` 的问题。报价统一按“有效现价 → 昨收 → 本机最近有效快照”回退，零值不会覆盖已有有效数据；完全没有历史数据时显示 `--`，不会参与资产盈亏计算。
- 最近有效报价会节流写入 VS Code 本地 `globalState`，因此关闭休市请求时，重启 VS Code 仍可立即恢复最近收盘价。
- 大盘云图首绘先完成离屏布局，再整体淡入；行业、细分行业和股票使用稳定节点 ID，缓存与网络数据相同时跳过重复布局，大云图禁用节点位移动画并合并尺寸重算，消除从左下角逐块展开和明显卡顿。
- 实时走势代理在扩展激活时仅预启动本机监听（不访问网络），同一股票重复点击不再重载，快速连续点击只打开最后选择的股票；东方财富页面模板在内存中缓存 5 分钟并合并并发请求，行情 GET/SSE 与休市门控保持不变。

## v1.3.2 修复

- 点开大盘云图或切换市场范围时，会先即时显示本地快照，再主动请求一次数据源的最近收盘云图并覆盖缓存；即使处于午休、盘后、周末或节假日也会执行这一次有限请求。
- 休市期间的后台云图轮询仍默认暂停，不会因为上述手动行为变成持续请求。重复的同范围并发请求会合并；更新失败时明确提示正在继续显示哪一份缓存。

## v1.3.1 修复

- 修复 VS Code 中实时走势 iframe 因 `frame-ancestors` 与 `vscode-webview:` 不兼容而被 Chromium 拦截的白屏问题；失败或超时时现在会显示可重试状态。
- 大盘云图会在本地保存最近成功快照并跨 VS Code 重载恢复。默认休市不联网，打开或切换范围时直接展示最近快照；右上角手动刷新仍可获取新数据。

## 功能

- 原生 VS Code TreeView 侧栏：我的持仓、A 股、指数，支持红涨绿跌、实时刷新和三态排序；排序按钮依次切换默认自选顺序、涨跌幅升序、涨跌幅降序，并分别作用于每个分组内部。
- LeekFund 风格的添加股票联想：在同一个输入框中按代码、名称或拼音实时显示匹配的 A 股及 A 股指数。
- 原创单色 SVG 图标系统：统一品牌、自选、资产、资讯、大盘云图、板块行情和操作按钮的尺寸与线宽，并将顶部栏压缩为 56px。
- LeekFund 同路线实时走势页：点击侧栏股票后打开或复用东方财富完整行情页，可切换分时、5 日、5/15/30/60 分钟、日 K、周 K、月 K，并查看资金流与逐笔成交。
- 实时页由仅监听 `127.0.0.1` 的随机端口和随机令牌代理承载，使用初始 GET 快照与 SSE 流式推送；iframe 与页面实例常驻，数据变化不会触发 Webview 整页重建。
- K 线沿用 LeekFund 的稳定性策略：日/周/月线优先使用搜狐历史日线转换，5/15/30/60 分钟线使用东方财富分时数据聚合；备源异常时才回到原始 K 线分片。
- 自选中心公司资料：展示企业简介、主营业务、所属行业、细分行业、相关概念和机构研报。
- 紧凑板块行情：提供关注板块、3 日涨幅、3 分钟涨速、行业/概念主力净流入 TOP10、全量行业与概念列表、排序搜索和板块成分股；支持关注板块、成分股查看走势及加入自选。
- 本地资产账本：数量、成本、股票市值、当日盈亏、持仓盈亏。
- 东方财富 7×24 市场资讯。
- 三级大盘云图：按“一级行业 → 细分行业 → 个股”呈现，支持 A 股全图、上证、深证、北交所、科创板和创业板范围；面积按总市值、颜色按涨跌幅。
- 状态栏展示上证指数和本地持仓盈亏。

## 行情刷新与交易时段

- `aShareLeek.refreshInterval` 默认是 `5000` 毫秒，允许范围是 `3000–300000` 毫秒；调度采用“本轮完成后再等待一个间隔”，因此实际周期为请求耗时加配置间隔。它只调度侧栏和韭菜中心，实时走势由 SSE 到达即更新。
- `aShareLeek.requestOutsideTradingHours` 默认是 `false`。关闭时，仅在北京时间工作日 `09:15–11:30`、`13:00–15:05` 放行自动行情请求；其余盘前、午间、盘后、周末和内置的 **2026 年**交易所节假日暂停股票/指数、云图、板块轮询与实时走势上游 SSE。手动打开或切换股票仍允许一次初始页面和快照请求；手动打开云图或切换云图范围会请求一次最近收盘快照。
- 侧栏、状态栏和资产共用同一份默认 5 秒报价快照；资产只在本地计算市值与盈亏，不发独立行情请求。休市不轮询时优先恢复本机最近有效报价；从未取得过报价的标的显示 `--`。
- 资讯仅在韭菜中心可见且“资讯”页激活时约每 `120` 秒更新，不受休市门控；公司资料按股票缓存 `30` 分钟，没有独立定时器。
- 云图仅在中心可见且“云图”页激活时约每 `300` 秒自动更新；休市时后台自动更新暂停。用户点开云图或切换范围时，先显示最近成功缓存，同时强制获取一次数据源当前可提供的最近收盘快照。板块总览/列表约每 `60` 秒、板块详情约每 `15` 秒更新，均遵循休市设置。所有子周期都由全局调度器检查，因此把全局间隔设得更大时，子模块不会快于全局间隔。
- 手动刷新和手动切换 K 线周期不受交易时段限制；实时走势无需按 5 秒手动刷新，交易时段内由 SSE 持续增量更新。
- 交易时段按北京时间判断；接口数据可能存在交易所或数据源延迟。

可在 VS Code 设置中搜索 `A股韭菜盒子` 修改这些选项。

## 构建与测试

需要 Node.js 20+ 与 VS Code 1.100+。

    npm install
    npm run check
    npm run package

确定性交易时段测试也可以单独运行：

    npm run compile
    node test/market-hours.js
    npm run test:proxy

生成的 VSIX 位于：

    dist/a-share-leek-1.3.5.vsix

安装：

    code --install-extension dist/a-share-leek-1.3.5.vsix --force

## 数据与隐私

- 行情、K 线、公司资料、资金流、最近成交、股票列表与资讯来自公开网络接口，接口可能调整、延迟或中断。
- 实时走势代理只监听本机回环地址并使用不可预测的临时令牌；浏览器代理入口只允许东方财富域名，服务端 K 线备源另固定访问 `q.stock.sohu.com`。关闭扩展时会同时关闭代理和 SSE 连接。
- 持仓、最近有效报价和最近成功的云图快照只保存在 VS Code 的本地 `globalState`，本扩展不连接券商账户，也不上传这些数据。
- 本扩展仅用于数据展示，不构成投资建议。投资有风险，入市需谨慎。
